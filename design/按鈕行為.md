# 按鈕行為完整分析

> 更新日期：2026-06-30

---

## `setInputEnabled(enabled)` 控制範圍

| 元素 | enabled=true | enabled=false |
|------|-------------|---------------|
| `inputEl` (#input textarea) | enabled | disabled |
| `sendBtn` (#send-btn) | enabled | disabled |
| `btnImport` (#btn-import) | enabled | disabled |
| `btnNew` (#btn-new) | enabled | disabled |
| `btnSave` (#btn-save) | enabled | disabled |
| `btnSettings` (#btn-settings) | enabled | disabled |
| 所有 `.tab-item` | `pointerEvents=""` | `pointerEvents="none"` |

**不受控（streaming 時仍可用）**：`btnStop`、`btnPopout`、`btnRegression`、`btnLogAnalysis`、`btnFontUp`、`btnFontDown`、`btnScrollDown`。

另有獨立的 `disableBottomInput()` / `enableBottomInput()` 控制 `inputEl`、`sendBtn`、`btnFontUp`、`btnFontDown`（onboarding 顯示時 disable）。

## 一、Header 按鈕

### 1. Pop-out ⧉ (`btn-popout`)

| 條件 | 行為 |
|------|------|
| sidepanel 模式 | 儲存 UI 狀態 → 發送 `popout_open` → 彈出獨立視窗 |
| popup 模式 | 儲存 UI 狀態 → 發送 `popout_close` → 回到 sidepanel |

- **確認**：無
- **啟用/停用**：不受 `setInputEnabled()` 控制，永遠可用
- popup 模式下 onboarding Import 按鈕會隱藏

### 2. Save 💾 (`btn-save`)

| 條件 | 行為 |
|------|------|
| 按下 | 將 chatArea 內容組成完整 HTML → Blob 下載 → toast "Chat saved as HTML" |

- **確認**：無
- **啟用/停用**：受 `setInputEnabled()` 控制

### 3. Import HSD (`btn-import`)

| 條件 | 行為 |
|------|------|
| tab URL 無 HSD ID | 顯示系統訊息提示開啟 HSD-ES 頁面 |
| 已有不同 `activeHsdId` | 彈 Modal「Switch HSD?」確認 |
| 確認/首次匯入 | 設定 `activeHsdId` → 更新 header → 生成 CID → 擷取 tab title → toast → `hsdImported=true` → 顯示 hero CTA 按鈕 |

- **確認**：僅在切換不同 HSD 時
- **狀態變更**：`activeHsdId`、`activeHsdTitle`、`activeConversationId`、`hsdImported=true`
- **啟用/停用**：受 `setInputEnabled()` 控制

### 4. New (`btn-new`)

| 條件 | 行為 |
|------|------|
| `sessions.length >= MAX_SESSIONS (6)` | 彈 Modal 提示已達上限，直接 return |
| session 為空 | 直接 `startNewSession()` |
| session 有內容 | 彈 Modal「離開目前 session？」確認後執行 |

**`startNewSession()` 流程：**
- 儲存目前 session → 清空 chatArea → 重設所有狀態
- 顯示 onboarding、隱藏 post-analysis / hero CTA
- sessions 陣列前方插入空 session，裁切至 MAX_SESSIONS
- 發送 `{ action: "start_session" }` 給 bridge，重設 `bridgeSessionCid`

- **確認**：有（除非 session 為空或已達上限）
- **啟用/停用**：受 `setInputEnabled()` 控制

### 5. Stop (`btn-stop`)

| 條件 | 行為 |
|------|------|
| 任何時候 | 直接發 `{ action: "stop_session" }` 給 bridge，無確認 |

**由 `session_stopped` handler 處理後續**：status 改 disconnected → 清除 streaming → 顯示「Session ended.」→ `setInputEnabled(false)`

- **確認**：無
- **啟用/停用**：不受 `setInputEnabled()` 控制，永遠可用

### 6. Regression "R" (`btn-regression`)

| 條件 | 行為 |
|------|------|
| 按下 | 切換到 Regression 畫面（隱藏 mainView、顯示 regressionView、header 變金色） |

- **確認**：無
- **啟用/停用**：不受 `setInputEnabled()` 控制。HTML 預設 disabled，由 `updateRegressionBtnState()` 控制 — 需同時有 `activeHsdId` 和 `activeHsdTitle` 才 enable
- **Feature Flag**：由 settings 的 `featureRegressionEnabled` 控制可見性

### 7. Log Analysis 📋 (`btn-log-analysis`)

| 條件 | 行為 |
|------|------|
| 按下 | 彈 Modal「Switch to Log Analysis Mode」確認 → 儲存 session → 清空狀態 → header 變深藍 → 顯示 log analysis bar → 重啟 bridge 為 `displaydebugger` assistant |

- **確認**：有
- **狀態變更**：`isLogAnalysisMode=true`、session 全部重設
- **啟用/停用**：不受 `setInputEnabled()` 控制。由 Feature Flag `featureLogEnabled` 控制 display 可見性

### 8. History ↺ (`btn-history`) — 已停用

- `const btnHistory = null;`，HTML `.history-wrap` 設 `display:none`
- 功能已被 Tab Bar 取代

### 9. Settings ⚙️ (`btn-settings`)

| 條件 | 行為 |
|------|------|
| 按下 | toggle 開關 settingsMenu（同時關閉 history menu） |

**Menu 內容：**

| 控制項 | 行為 |
|--------|------|
| Language (en/zh) | `applyLang()` → 更新 `uiLang`、localStorage、Send 按鈕文字（Send/送出） |
| Feature: Log Analysis checkbox | 彈確認 → 更新 `featureLogEnabled` → `applyFeatureFlags()` |
| Feature: Regression checkbox | 彈確認 → 更新 `featureRegressionEnabled` → `applyFeatureFlags()` |
| Debug Mode checkbox + Apply | 彈確認（是否重啟 Bridge）→ 儲存設定到 `chrome.storage.local` |

- **確認**：menu 開關無確認；feature toggle 有確認
- **啟用/停用**：受 `setInputEnabled()` 控制
- **關閉方式**：點外部、按 Escape

## 二、Log Analysis 面板按鈕

### 10. Browse Log 📁 (`btn-browse-log`)

- 發 `{ action: "file_dialog", field: "log" }` → 原生檔案選擇 → 填入 `logPathInput`
- 對話框期間自身 disabled（文字改為 ⏳）

### 11. Browse Man 📁 (`btn-browse-man`)

- 同上，field 為 `"man"`，填入 `manPathInput`

### 12. Analyze 🔍 (`btn-log-analyze`)

- 讀取 log 路徑（必填）+ man 路徑（選填）→ 組合 command → `sendUserMessage()`
- HTML 預設 disabled，`logPathInput` 有值時才 enable

## 三、Onboarding 按鈕

### 13. Import HSD 📥 (`onboarding-import-btn`)

- 呼叫 `importHsdFromWebpage()`，邏輯同 `btn-import`
- 不受 `setInputEnabled()` 控制
- popup 模式下隱藏

### 14. Go (`onboarding-go-btn`)

- 讀取 `onboarding-hsd-input` → `hideOnboarding()` → `sendUserMessage(val)` → 清空 input
- Enter 鍵也會觸發
- 不受 `setInputEnabled()` 控制

## 四、Chat Area 按鈕

### 15. Hero CTA 🚀 (`hero-cta-btn`)

- 由 `showImportQuickActions()` 動態綁定一次性 handler
- 按下：隱藏 CTA → `hsdImported=false` → `sendUserMessage("{hsdId} skip any attachment check and skip gdhm sherlog and etl log check", "Analyze HSD {hsdId}")`
- 僅在 Import HSD 後顯示
- 不受 `setInputEnabled()` 控制

### 16. Scroll Down ↓ (`btn-scroll-down`)

- 浮動圓形按鈕，使用者向上滾動 > 80px 時淡入，按下跳到底部並消失
- `userScrolledUp = false` → `forceScrollToBottom()`
- 位置動態計算：`inputArea 高度 + postAnalysisPanel 高度 + 12px`（ResizeObserver 監聽）
- 不受任何 enabled 控制

### 17. Send (`send-btn`)

- `sendUserMessage(inputEl.value)` → 清空 input

**`sendUserMessage()` 完整流程：**
1. 空白/無 port/`isStreaming` → return
2. 重設 scroll lock → 新增 user msg 到 chat → `setInputEnabled(false)`
3. 折疊 post-analysis panel → 追蹤 `sessionMessages`
4. 偵測 HSD ID（8-14 位數）→ 更新 header、生成 CID
5. `hsdImported` → prepend `[HSD xxxxx]`
6. `_pendingCidContextRestore` → prepend HSD context
7. `uiLang === "zh"` 且非 menu selection → 附加 `(請使用繁體中文回答)`
8. `bridgeSessionCid !== activeConversationId` → lazy restart bridge
9. `isStreaming = true` → 發 `{ action: "send", message }` → typing indicator

- **啟用/停用**：受 `setInputEnabled()` + `disableBottomInput()` 控制

### 18. Font + (`btn-font-up`)

- `chatFontSize += 1`（最大 22）→ 更新 CSS → localStorage
- 由 `disableBottomInput()` 控制，不受 `setInputEnabled()` 控制

### 19. Font − (`btn-font-down`)

- `chatFontSize -= 1`（最小 10），其餘同上

## 五、Post-Analysis 面板

### 20. Post-Analysis 快捷按鈕

由 `QUICK_ACTIONS_TABLE` 中 `show: "post-analysis"` 產生：

| 按鈕 | prompt |
|------|--------|
| 📋 Summary | Provide a brief summary... |
| 🔍 Potential Root Cause | What is the most likely root cause?... |
| 📝 Latest Action Items | List latest three comment's action items... |
| 🔄 More Similar issues | List 10 similar issues'... |

- 按下：collapse panel → `sendUserMessage(prompt, display)`
- Panel 首次出現條件：`onReady` 中 `accumulatedAnswer && activeHsdId && !_postAnalysisShown`
- Panel header 可點擊 toggle 展開/收合
- 不受 `setInputEnabled()` 控制

### 21. Quick-Action 按鈕（動態）

| 情境 | 產生的按鈕 |
|------|-----------|
| session ready | "always" group: Analyze, Summary, Root Cause, Next Steps |
| AI 回覆含 numbered list | 數字按鈕 + All, Skip |
| AI 提 yes/no 問題 | Yes, No |
| AI 回覆含 "Select: A, B, C" | 動態選項按鈕 |

- 按下：隱藏 quick actions → `sendUserMessage(prompt, display)`
- `isStreaming` 時 `sendUserMessage` 會 block

## 七、Tab Bar 互動

| 操作 | 行為 |
|------|------|
| 點擊 tab | `switchToSession(index)`（streaming 中會彈確認） |
| 點擊 tab × | `closeTab(index)`（永遠彈確認，streaming 中有額外警告） |
| 點擊 + | 觸發 `btnNew.click()` |

## 八、其他互動

| 元素/事件 | 行為 |
|-----------|------|
| `log-analysis-exit` | 恢復之前 session → 重啟 bridge 為 sighting_assistant |
| `post-analysis-header` click | Toggle panel 展開/收合 |
| 鍵盤 `Enter`（input textarea，無 Shift） | 觸發 `sendUserMessage` |
| 鍵盤 `Escape` | 關閉 history menu / settings menu |
| 點擊外部 | 關閉 history menu / settings menu |
| `visibilitychange` hidden | 自動 `saveCurrentSession()` + `persistSessions()` |
